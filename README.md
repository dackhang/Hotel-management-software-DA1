# 🏨 Hotel Management Software - DA1

> 🎓 Bài tập lớn môn: Phần mềm quản lý khách sạn sử dụng WinForms và SQL Server.

## 📌 Giới thiệu
Ứng dụng giúp quản lý toàn bộ hoạt động của khách sạn:
- Đặt phòng, trả phòng, quản lý tình trạng phòng.
- Quản lý khách hàng, dịch vụ đi kèm.
- Tạo hóa đơn, báo cáo doanh thu.
- Giao diện thân thiện, dễ sử dụng cho nhân viên lễ tân.

## 🛠️ Công nghệ sử dụng
- Ngôn ngữ: C# (WinForms)
- Cơ sở dữ liệu: SQL Server
- Công cụ: Visual Studio, Crystal Reports

## 🚀 Chức năng chính
- Quản lý phòng: đặt, trả, cập nhật tình trạng phòng.
- Quản lý khách hàng: thêm, sửa, xóa, tìm kiếm.
- Quản lý dịch vụ: gọi món, sử dụng dịch vụ.
- Hóa đơn & thống kê doanh thu theo ngày/tháng.
